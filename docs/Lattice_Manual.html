What each group does

Excel

  • Workbook: Save + Backup, Optimize (used ranges, broken names, unused styles), Share (values, PNG, health report).
  • Color: AutoColor (blue inputs, black formulas, green links, purple external, dark red embedded hard-codes), font / fill / border cycles, Black Fonts switch.
  • Model: format cascades; formulas ($ anchors, flip and IFERROR toggles, values, fast fill, exact paste, bare case drop-down); charts (football field, stacked + totals, waterfall, CAGR, growth rows, chart annotations: live totals, CAGR arrow, difference arrow); library (LBO, DCF, distribution waterfall, accretion / dilution, returns, debt, credit stats, Black-Scholes, sensitivity, scenario switch, timeline, run cases scenario table); cells, sheets, view.
  • Audit: Model Check pane and report, Trace In / Out windows, Ctrl+[ / ] jumps, Visualize (hard-codes, inconsistent formulas, errors).
  • Comps: stats rows, comps formatter, rank / percentile, outliers.
  • Export: to PowerPoint (picture, table, chart, native chart, embedded workbook) and Word; Match Width / Height / Size; Refresh deck.

PowerPoint

  • Presentation: template, backup, PDF, email, Agenda and section sync, Pagination, Deck Check, Deck Tools (harmonize / conform fonts, table formats, chart palette, notes, per-section PDFs).
  • Insert: Slide Library with Slide Links, Stickers (traffic lights, tick / cross, Harvey cycling, DRAFT-style stamps), Turbo Shapes, Master Shapes.
  • Color / Text: cycles, hex and theme colours, format painter, Styles, text tools, Select Match, Arrange Shapes.
  • Shapes: align to first shape or slide, distribute, gaps, same size, stretch, swap, remember / apply position, z-order, convert to picture.
  • Import / Links: Excel import with black fonts, Link Text, Match Size, Refresh (item / slide / deck), Explorer Pane, Highlight Links, Airplane Mode, V1 / V2 refresh prompt, go to source, change source, break link.

Word

  • Import from Excel as picture (black fonts) or table, refresh selection / document, links list, go to source, break link.
  • Document tools: strip double spaces, autofit tables, fit pictures to width, black fonts toggle.
